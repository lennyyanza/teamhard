# Images for HARD

- Gallery images: about **1600px wide**.
- Headshots: about **600 × 600px square**.
- Keep each image **under 300KB** where practical.
- Use **kebab-case** filenames: `hull-v1-render.jpg`, not `Hull Render FINAL.jpg`.
- Use **JPG** for photos and **PNG** for renders needing transparency.
- Put photos in `gallery/` and portraits in `team/`, then edit the matching file in `data/`.
- Describe the image in `alt`; write the date and context in `caption`.

The included SVG files are lightweight initial/blueprint placeholders. Replace their JSON paths with real photos as they become available. Missing team photos fall back to initials; missing gallery files show a neutral technical grid.

`hero-wireframe.svg` is an abstract concept schematic, not a CAD rendering. `favicon.svg` is the site icon. `social-preview.png` is the Open Graph sharing image.
